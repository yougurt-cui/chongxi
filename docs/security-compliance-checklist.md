## 一、谷子活动：安全整改

接口：`POST /api/miniprogram/image-generations`，输入 `image`、`prompt`、`request_id`。功能说明见前端仓库的 [谷子活动](../../xiaochengxu/docs/guzi-activity.md)（需同级检出前端仓库）。

### G-01 · P1 · 提示词和生成结果缺少应用侧内容审核

- [ ] 在调用生图模型前，对提示词及参考图执行适用的安全审核；在展示、下载或发布结果前完成结果审核。
- [ ] 明确拒绝、待审核、审核失败状态；审核不可用时不得直接放行为成功结果。
- [ ] 若产品限定宠物徽章，使用服务端维护的模板和受限自定义字段，并校验业务范围。模板不能替代安全审核。

**证据：** `services/miniprogram_image_generation_service.py` 的 `validate_input` 仅对提示词做非空及 2000 字限制；`generate_reference_image` 原样传递提示词；`_run` 生成后直接保存并标记成功，未接入应用侧审核。预设提示词可完全被用户改写。

**影响：** 可把活动当作通用生图入口，输出超出活动范围或不适宜的内容。供应商可能有自身拦截，其配置和覆盖面尚未验证。

**验收：** 覆盖拒绝输入、待审结果、审核超时及失败；直接调用 API 也执行同样审核；未通过结果不能获取可下载链接。

### G-02 · P1 · 缺少累计次数及费用上限

- [ ] 增加账号每日额度、短时请求频率限制及全局费用预算，并使用跨进程共享的原子计数。
- [ ] 明确额度扣减、失败返还和幂等重试规则；配置异常用量告警及停止生图开关。
- [ ] 对多账号／多 IP 滥用设置分层控制，避免仅依赖 IP 影响正常共享网络用户。

**证据：** `create_task` 有单账号一个活动任务的数据库唯一约束、幂等请求和每进程四个任务槽位，但没有每日次数或累计费用判断。任务结束后可更换 `request_id` 再次提交。

**影响：** 并发受限但总消费不受限；多进程部署会增加总任务槽位。

**验收：** 达到账号／全局额度后不再调用供应商；并发请求不能突破额度；重复请求不重复计费。

### G-03 · P1 · 生图结果链接无需登录即可读取

- [ ] 私有生成结果改用归属校验下载或短时有效的签名链接，避免复用永久公开的动态图片入口。
- [ ] 将“个人生成结果”和“用户主动公开发布的图片”分开管理，并定义删除和缓存失效行为。

**证据：** `_run` 调用 `upload_moment_image` 保存结果；`api/miniprogram_api.py` 中 `GET /moment-images/<file_id>` 不验证访问者身份。任务查询 `_find` 有用户归属校验，但不保护后续图片下载。

**影响：** 知道链接的人可读取结果。随机 ID 降低猜中概率，但不能替代授权。

**验收：** 用户 B 和匿名请求无法访问用户 A 的未公开结果；过期／撤销链接失效；公开发布流程仍正常。

### G-04 · P2 · 图片处理发生在任务限流前

- [ ] 在高成本图片解码前增加轻量请求限流；核实网关和应用的请求体上限、上传超时。
- [ ] 为解码处理设置并发边界，确保忙碌或重试请求不会持续占用图片处理资源。

**证据：** `create_task` 先执行 `validate_input` 解码和重新编码，之后才检查幂等任务、获取 `_slots` 和插入活动任务。接口有声明长度检查、文件读取上限和像素上限，但这些不等于请求频率限制。

**验收：** 本地／测试环境重复提交时，限流在解码前生效；大请求在进入业务处理前被拒绝。

## 三、其他输入接口：已发现问题

### S-01 · P0 · 私密动态列表缺少所有者限制

- [ ] 私密列表必须登录，并强制使用当前登录用户 ID；公共列表不能通过 `visibility` 参数切换到其他人的私密内容。
- [ ] 增加匿名访问、跨用户访问及正常本人访问的回归测试。

**证据：** `api/miniprogram_api.py:list_moments_endpoint` 接收客户端 `visibility`；`services/miniprogram_moment_service.py:list_moments` 在 `include_private=False` 时只按可见性过滤。隔离验证中，匿名传入 `visibility=private` 生成如下查询：

```sql
SELECT * FROM moments
WHERE status='active' AND visibility=%s
ORDER BY created_at DESC, id DESC LIMIT %s
-- 参数：['private', 20]；缺少 user_id 条件
```

**影响：** 若线上部署相同逻辑且存在私密数据，可能泄露正文、图片和用户关联信息；未在线读取验证。

### S-02 · P1 · 动态上传未验证真实图片格式

- [ ] 在 `/moment-images` 中解码验证图片、限制像素并重新编码，统一处理错误和清理临时文件。

**证据：** `services/miniprogram_moment_image_service.py:_normalize_upload_file` 仅检查文件名／声明 MIME；隔离验证中普通文本以 JPG 声明可通过现有检查。

**边界：** 谷子输入照片另有真实图片解码和重新编码，不能将此问题直接套用到谷子输入端；谷子结果也会先解码再保存。未据此认定可执行代码或 XSS。

### S-03 · P1 · 动态上传体积限制执行过晚

- [ ] 鉴权后再解析上传内容；应用和网关设置总请求体上限；采用有界读取和写入，异常时清理文件。

**证据：** `/moment-images` 在鉴权前访问 `request.files`；本地存储先完整写盘再检查 10MB，OSS 路径 `_read_upload_bytes` 先完整读入内存；检查到的 Flask 配置未设置统一请求体上限。

**影响：** 存在内存、磁盘与处理资源耗尽风险；线上可利用程度取决于网关等外层限制，尚待核实。

### S-04 · P1 · 动态图片审核完成前即公开

- [ ] 图片审核等待期间保持帖子不可公开；全部通过后再发布；正确处理风险回调、回调重试和到达顺序。

**证据：** `services/miniprogram_content_review_service.py:submit_image_with_wechat` 返回 `async_pending`；`services/miniprogram_moment_service.py:create_moment` 随后写入 `active`。风险回调到达后才隐藏。

**验收：** 待审帖子不能从公共列表、详情及相应媒体访问路径绕过限制；审核通过与拒绝均可追踪。

### S-05 · P2 · 部分接口原样返回内部异常

- [ ] 将非预期异常映射为统一文案和追踪 ID；服务端日志保留必要排障信息并脱敏。

**证据：** `api/miniprogram_api.py` 多个接口以 `str(exc)` 返回 500 错误。潜在泄露范围取决于实际异常内容，未在线触发验证。

**边界：** 谷子 `_run` 已使用通用失败文案，不回传供应商异常正文，不属于该项主要问题路径。

## 四、已有保护与回归基线

- 谷子接口使用 Bearer 登录身份；任务查询限定 `user_id`，未发现客户端指定他人身份的路径。
- 提示词后端限制 2000 字；SQL 使用参数绑定；提示词作为 JSON 字符串传给固定配置的上游，没有发现 shell／eval 执行或由提示词指定请求地址的路径。
- 提示词没有接入代码执行工具；本次未发现它可以直接读取服务器密钥。模型偏离宠物徽章任务与服务器被入侵是不同风险。
- 谷子参考图限制 10MB，真实解码 JPG／PNG，限制像素和比例，缩放并重新编码；不能仅伪造 MIME 绕过。
- 有请求幂等、输入摘要、单账号活动任务唯一约束和每进程任务槽位；这些保护须在增加审核／配额时保留。
- 已有 `chongxi/tests/test_miniprogram_image_generation.py` 覆盖部分输入、鉴权、幂等、归属及失败处理；本次仅阅读，未重新运行，不代表覆盖本清单新增整改项。
