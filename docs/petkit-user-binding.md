# 用户小佩连接部署

新增用户接口与既有管理员 `/api/petkit` 采集器完全隔离，禁止将管理员会话作为用户连接使用。

## 配置

安装 requirements.txt（新增 cryptography）。运行 Python 须可导入 pypetkitapi 1.31.1；子进程使用当前 Python，不读取管理员 env/session 文件。

- PETKIT_USER_ENABLED=1：显式开启；关闭时不能新连或同步。
- PETKIT_SESSION_KEY：Fernet 密钥，由部署者通过密钥管理注入，不提交仓库。可用 `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"` 在受控终端生成。保持稳定；更换后旧会话需要重新连接。
- PETKIT_PRIVACY_OPERATOR：真实运营主体。
- PETKIT_PRIVACY_CONTACT：真实隐私联系渠道。
- PETKIT_USER_DB：默认 var/petkit-users.sqlite3，配置持久化绝对路径，限制服务账号访问。

缺少主体、联系方式或有效密钥时入口可以查看但不能提交账号。公开政策接口不返回任何个人数据。部署者需将设备补充条款合并至完整隐私协议；备份制度和删除流程须与披露一致。本模块默认不创建备份。

## 运行限制

当前适用于单主机、共享同一个 SQLite 文件的低流量试运行。事务锁串行化设备请求与撤回：上游最多 22 秒，其他写操作可能收到 503 BUSY，应稍后重试。不要将 SQLite 放到多主机网络盘；扩容前迁移至共享数据库和有租约的任务队列。网关请求超时应超过 25 秒。每用户每分钟最多 5 次连接/刷新/同步尝试，包括失败尝试。

连接通过 stdin 管道提交到短生命周期子进程；不把用户名/密码放进参数、文件、环境变量或持久队列。关闭子进程日志，异常只映射固定消息。必须同时关闭反向代理、APM、异常采样对该接口的请求体记录，并禁止服务进程 core dump，才能兑现整个部署链路不保留密码的承诺。

会话以 Fernet 加密；保存会话必要字段、提供方用户标识摘要、设备标识和白名单状态/事件。未调用视频接口或远程控制接口。未绑定连接 15 分钟过期，过期会话在下一次成功设备数据库操作时清除。有效期检查也清除已到期会话。不自动使用密码重登。

同步目前为有界同步调用，结果存为 job 供前端读取；同一连接只保留最近结果。没有后台定时任务。断开清除会话；保留历史仅可读取，重新连接不会恢复已归档设备的同步。单台解绑删除该台快照与事件；断开可删除全部历史。SQLite secure_delete 开启；外部备份删除由部署策略负责。

测试使用仿真上游响应，覆盖身份隔离、绑定冲突、加密和删除等服务逻辑。未进行真实小佩账号/设备联调；上线前须验证中国区账号、具体喂食器和饮水机型号。只展示已返回的数据字段，未提供数据与零不同，不计算宠物实际摄入量。
